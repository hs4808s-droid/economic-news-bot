# 4단계: 발송용 텍스트 생성

`logs/<오늘날짜 YYYY-MM-DD>/3_report.md`를 읽고, 실제 발송에 쓸 텍스트 파일을 만든다.
(실제 메일 발송은 이 단계에서 하지 않는다. 별도 스크립트(send_email.js)가 이 파일을 읽어 Gmail API로 발송한다.)

## 변환 규칙
- 본문은 단순 텍스트(plain text)로 변환한다. HTML이나 마크다운 기호(#, **, - 등)는 제거하고 줄바꿈과 들여쓰기로만 구조를 표현한다.
- 리포트의 5개 섹션 구조(시장 개요 / 연준·금리 / 주요 경제지표 / 특징 종목·뉴스 / 종합 시사점)는 유지한다.

## 출력
다음 경로에 정확히 아래 형식으로 저장한다: `logs/<오늘날짜 YYYY-MM-DD>/email_to_send.txt`

```
Subject: [경제 뉴스 리포트] YYYY-MM-DD 미국 시장 요약

(여기부터 본문 - plain text)
...
```

1번째 줄은 반드시 `Subject: ...`로 시작하고, 2번째 줄은 빈 줄, 3번째 줄부터 본문이어야 한다.
