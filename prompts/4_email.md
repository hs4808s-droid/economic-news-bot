# 4단계: 발송용 텍스트 생성

`logs/<오늘날짜 YYYY-MM-DD>/3_report.md`를 읽고, 실제 발송에 쓸 텍스트 파일을 만든다.
(실제 메일 발송은 이 단계에서 하지 않는다. 별도 스크립트(send_email.js)가 이 파일을 읽어 Gmail API로 발송한다.)

## 리포트 링크 (본문 최상단)
- `package.json`의 `homepage` 값을 Read해서 다음 URL을 만든다: `<homepage>reports/<오늘날짜 YYYY-MM-DD>.html`
- 이 URL을 본문 **첫 줄**에 `전체 리포트: <URL>` 형태로 넣고, 그 다음 빈 줄을 둔 뒤 본문을 이어 쓴다.
  - 예: `전체 리포트: https://hs4808.github.io/economic-news-bot/reports/2026-09-14.html`
- ⚠️ 링크가 생겼다고 **본문을 요약하지 않는다.** 메일에는 리포트 전문이 그대로 들어간다.

## 변환 규칙
- 본문은 단순 텍스트(plain text)로 변환한다. HTML이나 마크다운 기호(#, **, - 등)는 제거하고 줄바꿈과 들여쓰기로만 구조를 표현한다.
- `3_report.md`의 섹션 구조와 순서를 그대로 유지한다 (TOP 순위 / 시장 개요 / 선물·변동성 구조 / 연준·금리 / 경제지표 / 특징 종목 / 섹터별 동향 / AI 밸류체인 / 수급·내부자 / 기타 이슈 / 향후 일정 / 종합 시사점 / 확인 필요).
- 표는 plain text에서 깨지므로 `항목: 값 (등락률)` 같은 줄 단위로 풀어 쓴다. **수치는 생략하지 않는다.**

## 출력
다음 경로에 정확히 아래 형식으로 저장한다: `logs/<오늘날짜 YYYY-MM-DD>/email_to_send.txt`

```
Subject: [경제 뉴스 리포트] YYYY-MM-DD 미국 시장 요약

(여기부터 본문 - plain text)
...
```

1번째 줄은 반드시 `Subject: ...`로 시작하고, 2번째 줄은 빈 줄, 3번째 줄부터 본문이어야 한다.
